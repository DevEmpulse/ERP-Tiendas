**Stack Detectado:** Next.js 16 (App Router) + React 19 + TypeScript + Tailwind CSS v4 + Supabase

## Flujos de Desarrollo SDD
- **Explore**: Investigación y análisis de requisitos.
- **Propose**: Definición de propuesta de solución o arquitectura.
- **Spec**: Especificación de funcionalidades, interfaces y APIs.
- **Design**: Diseño de componentes UI / Esquema de base de datos.
- **Implement**: Construcción iterativa guiada por especificaciones.
- **Verify**: Verificación y pruebas (`pnpm build`, `pnpm lint`, RLS & Auth validation).

## Estado del Proyecto y Capacidades de Prueba

- **Estilos**: Tailwind CSS v4, Shadcn UI, Base UI
- **Backend & DB**: Supabase (Auth, RLS multi-tenant por `store_id`)
- **Herramientas de Verificación**: `pnpm build`, `pnpm lint`
